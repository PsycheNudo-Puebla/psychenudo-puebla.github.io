# Sistema de Rúbricas Interactivas

Este espacio contiene la herramienta de evaluación interactiva para asegurar la calidad de los contenidos en **PsycheNudo Puebla**.

## Herramientas
*   **[Rúbrica de Evaluación](./index.html)**: Aplicación web local para la calificación de artículos y perfiles profesionales.

*Nota: Esta herramienta funciona de manera offline. Los datos se guardan en el navegador y pueden descargarse como respaldo JSON, tabla CSV/Excel o informe PDF para su almacenamiento permanente.*

*El informe del grupo incluye únicamente a los alumnos del grupo activo. Las calificaciones guardadas de otros grupos pueden borrarse desde «Ver historial por grupo»: por alumno, por grupo o todas las de la rúbrica a la vez.*
